# Electron 跨平台一键打包脚本复刻指南

本指南帮助你将 `infinitynote` 项目的全平台一键打包方案迁移到你的其他 Electron 项目，实现一键或按需打包 macOS、Windows、Linux 客户端。

---

## 1. 环境准备

- Node.js >= 20.x
- npm >= 10.x
- Electron 项目已集成 [electron-builder](https://www.electron.build/)

> 推荐在 package.json 的 devDependencies 添加：
>
> ```json
> "electron-builder": "^26.0.0"
> ```

---

## 2. 脚本文件准备

1. **复制脚本**
   - 将 `infinitynote/scripts/build-all.sh` 复制到你的项目 `scripts/` 目录下。
   - 如无 `scripts/` 目录请新建。

2. **根据你的项目实际情况调整脚本内容**
   - 检查 `npm run build` 是否为你的前端/主进程构建命令。
   - 检查 `release/`、`dist/` 等目录名是否与你项目一致。
   - 如有特殊依赖或构建流程，按需修改脚本。

---

## 3. package.json 配置

在 `package.json` 的 `scripts` 字段添加：

```json
"electron:build:all": "bash scripts/build-all.sh",
"electron:build:mac": "npm run build && electron-builder --mac",
"electron:build:win": "npm run build && electron-builder --win",
"electron:build:linux": "npm run build && electron-builder --linux"
```

如需一键全平台打包，执行：

```bash
npm run electron:build:all
```

如需单独打包：

```bash
npm run electron:build:mac   # 仅 macOS
npm run electron:build:win   # 仅 Windows
npm run electron:build:linux # 仅 Linux
```

---

## 4. electron-builder 配置

确保你的 `electron-builder` 配置（可在 `package.json`、`electron-builder.json` 或 `electron-builder.yml`）已正确设置：

- `files` 字段包含你的主进程、渲染进程产物
- `mac`、`win`、`linux` 字段根据需求配置包名、图标、签名等

参考：[electron-builder 官方文档](https://www.electron.build/configuration/configuration)

---

## 5. 产物输出

- 所有安装包、校验文件、清单等会输出到 `release/` 目录
- 可根据脚本自定义输出内容

---

## 6. 常见问题

- **权限问题**：确保 `build-all.sh` 有可执行权限：
  ```bash
  chmod +x scripts/build-all.sh
  ```
- **依赖问题**：如遇 `electron`、`electron-builder` 相关依赖未安装，先执行：
  ```bash
  npm install
  ```
- **平台兼容**：macOS 下可打包 Windows/Linux，但打包 Windows 需 `wine` 支持（可选）。

## 重点说明：在 macOS 上打包多端

- **macOS 是唯一可以打包 macOS、Windows、Linux 三端的操作系统**（Windows/Linux 无法打包 macOS）。
- 脚本和 electron-builder 支持在 macOS 上一键生成所有平台的安装包。
- 打包 Windows 版本时，建议提前安装 `wine`，否则可能无法生成 .exe 安装包。
- 脚本会自动调用 electron-builder 的多平台参数：
  - `npx electron-builder --mac --x64 --arm64` 生成 macOS Intel/ARM 包
  - `npx electron-builder --win --x64` 生成 Windows 包
  - `npx electron-builder --linux --x64`、`--arm64` 生成 Linux 包
- 产物全部输出到 `release/` 目录，便于统一管理和发布。

---

## 重点：如何在 Mac 上打包 Windows 应用

1. **只需一台 Mac（M1/M2/Intel 均可）**，无需 Windows 设备或虚拟机。
2. **核心依赖**：
   - `electron-builder`（已在本项目配置）
   - 可选：如需生成 Windows 安装包（.exe），建议安装 wine：
     ```bash
     brew install --cask wine-stable
     ```
   - 没有 wine 也能生成 Windows 的 portable/zip 包，但不能生成完整 .exe 安装包。
3. **打包命令**：
   - 一键全平台：
     ```bash
     npm run electron:build:all
     # 或 bash scripts/build-all.sh
     ```
     按提示选择“所有平台”或“仅 Windows”即可。
   - 单独 Windows：
     ```bash
     npm run electron:build:win
     # 或 npx electron-builder --win --x64
     ```
4. **产物输出**：
   - Windows 安装包、portable 包、zip 包会自动输出到 `release/` 目录。
5. **配置说明**：
   - `electron-builder.json` 里 `win.target` 已配置 nsis/portable/zip，支持 x64/ia32。
   - 只需保证主进程/渲染进程产物、图标等资源路径正确。

---

> 你只需在 Mac 上运行上述命令，electron-builder 会自动帮你生成 Windows 客户端，无需任何 Windows 设备。
