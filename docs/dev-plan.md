# InfinityNoteX 后续开发计划

> 更新日期：2026-01-25

## 总体目标

- **稳定性与性能优先**：提升大数据量下的响应与可靠性。
- **可扩展的同步与协作**：在现有 WebDAV 基础上拓展更多 Provider。
- **AI 与知识库持续进化**：提升配置体验与检索质量。

---

## 里程碑规划（建议）

### M1（1~2 个月）稳定性与体验

- 便签列表与编辑器性能优化（大列表、频繁切换）
- 无限画布性能优化与内存压力评估
- 任务清单刷新策略与 UI 细节打磨
- 崩溃与异常日志收敛（更易定位问题）

### M2（3~4 个月）同步与数据安全

- WebDAV 同步可靠性提升（冲突提示、可视化状态）
- 增量同步策略优化与错误恢复流程
- 备份/还原流程 UX 优化（进度与结果报告）

### M3（5~6 个月）同步扩展

- Supabase Provider（配置与联调）
- Yjs Provider（协同同步能力验证）
- 本地文件夹同步 Provider

### M4（6~9 个月）AI 与知识库

- 知识库索引速度与稳定性优化
- AI 配置体验提升（模型预设与一键测试）
- 对话历史管理优化与更完善的提示信息

### M5（持续）发布与质量

- 自动化发布流程完善
- 回归测试与关键路径用例补充
- 性能与稳定性监控指标建设

---

## 风险与依赖

- 同步能力依赖远端服务稳定性与网络条件。
- 大规模数据场景需持续评估资源占用与性能瓶颈。
- AI 能力受限于外部服务可用性与模型兼容性。

---

## 交付建议

- 每个里程碑保持 2~4 周的小版本节奏。
- 每次版本都覆盖：性能、稳定性、数据安全三类回归。
- 重要功能发布前提供迁移与回滚方案。
