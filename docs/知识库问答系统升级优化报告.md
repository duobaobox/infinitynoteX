## 一、产品核心理念：搜-写-查闭环

### 1.1 闭环模型解读

InfinityNoteX 的产品灵魂可以用三个字概括：**搜-写-查**。这是一个持续循环、相互增强的知识管理闭环：

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│    ┌─────────┐        ┌─────────┐        ┌─────────┐           │
│    │   搜    │───────▶│   写    │───────▶│   查    │           │
│    │ Search  │        │  Write  │        │  Query  │           │
│    └────┬────┘        └────┬────┘        └────┬────┘           │
│         │                  │                  │                 │
│         │   AI 辅助发现    │   AI 辅助创作    │   AI 智能问答    │
│         │   外部信息检索    │   知识内化沉淀    │   知识库检索     │
│         │                  │                  │                 │
│         └──────────────────┴──────────────────┘                 │
│                            │                                    │
│                            ▼                                    │
│                    ┌───────────────┐                            │
│                    │   知识增长    │                            │
│                    │ 持续循环增强  │                            │
│                    └───────────────┘                            │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 1.2 三环节详解

| 环节            | 定义                     | 用户行为                       | AI能力要求                         |
| --------------- | ------------------------ | ------------------------------ | ---------------------------------- |
| **搜 (Search)** | 从外部世界获取信息       | 互联网搜索、资料阅读、灵感捕捉 | AI搜索引擎、信息摘要、关键信息提取 |
| **写 (Write)**  | 将信息内化为个人知识     | 笔记撰写、思考整理、观点输出   | AI写作辅助、格式优化、内容扩展     |
| **查 (Query)**  | 从知识库中检索和应用知识 | 知识问答、跨笔记总结、关联发现 | RAG检索、语义理解、上下文生成      |

### 1.3 闭环价值

- **搜→写**：外部信息转化为个人知识资产
- **写→查**：知识沉淀后可随时检索利用
- **查→搜**：知识缺口驱动新一轮信息获取
- **正向飞轮**：使用越多，知识库越丰富，AI越智能

### 4.3 Phase 2: 查能力深化（2-3周）

#### 4.3.1 混合搜索（Hybrid Search）

结合向量语义搜索和关键词搜索：

```typescript
async function hybridSearch(query: string, topK: number = 3): Promise<KnowledgeSearchResult[]> {
  // 1. 并行执行两种搜索
  const [vectorResults, keywordResults] = await Promise.all([
    semanticSearch(query, topK * 2),
    keywordSearch(query, topK * 2),
  ]);

  // 2. RRF 融合排序
  const fusedResults = reciprocalRankFusion(
    [vectorResults, keywordResults],
    topK,
    60, // k 参数
  );

  return fusedResults;
}

function keywordSearch(query: string, topK: number): KnowledgeSearchResult[] {
  // 使用 SQLite FTS5 全文搜索
  const sql = `
    SELECT noteId, noteTitle, content, 
           bm25(notes_fts) as score
    FROM notes_fts
    WHERE notes_fts MATCH ?
    ORDER BY score
    LIMIT ?
  `;
  // ...
}

function reciprocalRankFusion(
  resultSets: KnowledgeSearchResult[][],
  topK: number,
  k: number = 60,
): KnowledgeSearchResult[] {
  const scoreMap = new Map<string, { score: number; result: KnowledgeSearchResult }>();

  for (const results of resultSets) {
    results.forEach((result, rank) => {
      const existing = scoreMap.get(result.noteId);
      const rrfScore = 1 / (k + rank + 1);

      if (existing) {
        existing.score += rrfScore;
      } else {
        scoreMap.set(result.noteId, { score: rrfScore, result });
      }
    });
  }

  return Array.from(scoreMap.values())
    .sort((a, b) => b.score - a.score)
    .slice(0, topK)
    .map((item) => item.result);
}
```

async function rerankResults(
  query: string,
  candidates: KnowledgeSearchResult[],
): Promise<KnowledgeSearchResult[]> {
  // 方案1：使用 LLM 评分
  const prompt = `评估以下文档与问题的相关性（0-10分）。只输出数字分数。

问题：${query}

文档：
${candidates.map((c, i) => `[${i}] ${c.excerpt}`).join('\n\n')}

格式：每行一个分数，对应文档序号`;

  const response = await llm.generate(prompt);
  const scores = response.split('\n').map((s) => parseFloat(s.trim()));

  return candidates
    .map((c, i) => ({ ...c, rerankScore: scores[i] || 0 }))
    .sort((a, b) => b.rerankScore - a.rerankScore);
}

#### 4.6.1 知识图谱

// 自动发现关联
async function discoverRelations(noteId: string): Promise<KnowledgeEdge[]> {
  const note = await getNote(noteId);
  const embedding = await embed(extractNoteText(note.content));

  // 1. 向量相似度关联
  const similarNotes = await vectorStore.search(embedding, 10);

  // 2. 实体共现关联
  const entities = await extractEntities(note.content);
  const cooccurringNotes = await findNotesWithEntities(entities);

  // 3. 显式链接
  const explicitLinks = extractWikiLinks(note.content);

  return mergeRelations(similarNotes, cooccurringNotes, explicitLinks);
}

## 十、总结

InfinityNoteX 的产品灵魂是 **搜-写-查闭环**：

- **搜**：从外部世界获取信息，AI 辅助发现和提炼
- **写**：将信息内化为个人知识，AI 辅助创作和优化
- **查**：从知识库中检索和应用，AI 智能问答和关联

通过五个阶段的系统升级，InfinityNoteX 将从一个基础的笔记+RAG工具，进化为一个完整的 **AI驱动个人知识管理系统**，帮助用户：

1. 更高效地**获取**知识（搜）
2. 更流畅地**沉淀**知识（写）
3. 更智能地**利用**知识（查）

**核心差异化**：本地优先、隐私可控、完整闭环、模型自由。
